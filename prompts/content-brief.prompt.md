# Prompt — Content Brief Generation

**Agent:** [content-brief](../agents/content-brief.md) · **Output:** `../outputs/`

---

```
[Shared preamble — see prompts/README.md]

TASK: Produce a reviewer-ready content brief (NOT finished copy) for {{target keyword/topic, e.g. "Healthcare Security Services Australia"}}.

INPUTS: ../data/keywords/ (cluster), ../data/competitors/ + ../data/reports/ (gaps), ../outputs/ (GEO/AEO recs).
AUDIENCE: {{which of the 6 buyer audiences}}.

BRIEF MUST INCLUDE:
1. Target keyword + secondary keywords + cluster
2. Search intent + audience
3. Proposed title (<=60 chars) + meta description (<=155 chars), AU English
4. Outline: H1 + H2/H3 structure
5. Entities & topics to cover (GEO)
6. Direct-answer blocks / FAQs (AEO) — concise 40-60 word answers
7. Internal links: target pages within the 3/6/9 interlinking scheme
8. External references / evidence to cite
9. Word-count range + tone (Smart. Safe. Secure.)
10. Schema note — flag only schema NOT already auto-generated by Yoast (client-profile §5)

OUTPUT: one Markdown file to ../outputs/{{slug}}-brief.md, headed "DRAFT BRIEF — REVIEW BEFORE USE".

Produces briefs, not published content. A human writes and reviews the copy. Cite keyword/competitor sources.
Mirror into the Airtable Content Calendar table when asked.
```
